## 4. 准备如何开发或改造

会话节点 ID 与 Session ID 解耦；维护运行实例和状态；异常退出能被识别。。实现时：会话 ID 与图节点 ID 明确分离；关闭前台面板不停止进程；崩溃后对未能恢复会话显示状态。 与 持久会话状态不同于 OS 进程存活；不能仅凭数据库 running 标志认定进程仍运行。。关键异常必须有明确处理结果，不能仅改变画布表现而绕过真实数据校验。
