## 3. 节点职责

- **04.01 统一 CLI 适配接口**：屏蔽 Claude Code、Codex 等 CLI 的能力差异。。开发入口见任务 T-01。
- **04.02 多会话进程管理**：独立启动、持续运行、停止和恢复真实 Agent 会话。。开发入口见任务 T-02。
- **04.03 工具调用审批**：在保持 CLI 原生权限机制下展示与处理授权请求。。开发入口见任务 T-03。

## 4. 与其他系统的交接

输入：新建、输入、停止与审批请求；输出：流式事件、生命周期状态和 CLI 执行结果。 相关关系见[00 整体总览](../00-整体总览.md)；具体开发入口见下方任务行。

## 5. 当前开发或改造方案

第一版建议 Local-first 桌面运行时。为每类 CLI 实现适配器；优先结构化 API/SDK/协议，必要时再用 PTY 后备。默认尊重各 CLI 的审批能力，不能因进入协作画布而放宽安全权限。

本系统属于从零开发的**目标设计**，暂无已完成产品功能。技术选型均为建议或待验证方案，真实实现与验收进度应从文件开发文档更新。
