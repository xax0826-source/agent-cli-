## 4. 准备如何开发或改造

消息路由通过真实 source/target 会话与 edgeId 校验，拒绝子流程组级派发。。实现时：发送前以真实边 ID 校验会话端点权限；聚合边不能成为路由地址；是否自动触发下游执行列为待确认策略。 与 RealSessionEdge 只保存 sourceSessionNodeId / targetSessionNodeId；ProjectedEdge 是只读查询结果，不写回持久化层。。关键异常必须有明确处理结果，不能仅改变画布表现而绕过真实数据校验。

### 消息授权不从聚合边推断

用户可能在父层看见一条 `子流程 A→子流程 B ×3` 的只读投影边，但这不意味着 A 内任何 Agent 都能向 B 内任何 Agent 发送消息。消息路由必须以具体源会话、目标会话及对应的**底层真实边**进行校验。投影的 `underlyingEdgeIds` 仅用于定位相关连接，绝不能把父层节点 ID 当成 Agent 会话或消息收件人。
