让有真实连线的会话安全交换消息，并记录投递与运行活动。

## 3. 节点职责

- **05.01 会话间消息派发**：沿经过授权的真实会话边发送消息/任务。。开发入口见任务 T-01。
- **05.02 消息回执与失败处理**：管理投递、接受、完成、失败状态。。开发入口见任务 T-02。
- **05.03 运行状态逐级汇总**：从会话状态与真实边活动生成聚合节点及连线的明灭状态。。开发入口见任务 T-03。

## 4. 与其他系统的交接

输入：发送端会话、接收端会话、真实边 ID、Agent 事件；输出：消息回执、实时状态与聚合活动。 相关关系见[00 整体总览](../00-整体总览.md)；具体开发入口见下方任务行。

## 5. 当前开发或改造方案

真实会话边是跨 Agent 通信权限与可观察关系的基础方案；不从分层视图聚合边直接派发消息。消息路由前验证底层真实边。是否需要按连线自动触发执行、边方向和任务依赖语义尚需产品确认；首版按明确任务消息与回执实现。

本系统属于从零开发的**目标设计**，暂无已完成产品功能。技术选型均为建议或待验证方案，真实实现与验收进度应从文件开发文档更新。
