## 4. 准备如何开发或改造

校验循环包含、悬空引用、流程节点误连线；后端写入时重复检查。。实现时：只接受经过校验的领域对象；更新节点层级后真实边的端点 ID 不变；事务写入。 与 统一阻止任一端点是 subflow 的连接；UI 禁用仅是提示，持久化层还需强制验证；自环及重复连接策略保持待确认。。关键异常必须有明确处理结果，不能仅改变画布表现而绕过真实数据校验。

### 必须同时存在的两道校验

- **交互层**：子流程节点不显示可创建真实连线的端口，分层视图的聚合边不显示编辑操作。选择两个会话叶节点时才允许发起创建。
- **数据层**：不信任客户端传来的 `sourceNodeId`/`targetNodeId`。创建边前查出两端业务节点类型；任意端点非 `session` 即拒绝，无论当前画布处于何种视图。

删除流程图节点时需要明确是禁止删除存在连接的子树还是级联清理实际边，这一行为尚未由用户确定；初版建议提示并让用户确认，实际验收前需确认最终策略。
