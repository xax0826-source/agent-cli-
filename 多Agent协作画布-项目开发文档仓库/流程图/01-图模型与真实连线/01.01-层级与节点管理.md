## 4. 准备如何开发或改造

创建子流程或会话节点，移动到其他父流程，保证无包含环；节点 ID 稳定。。实现时：以纯 TypeScript 类型及运行时校验基础类型定义唯一数据契约；禁止在 Flow 对象中保存所谓父流程聚合边。 与 只接受经过校验的领域对象；更新节点层级后真实边的端点 ID 不变；事务写入。。关键异常必须有明确处理结果，不能仅改变画布表现而绕过真实数据校验。

### 层级数据不变量

- 一个项目有唯一根流程（`RootFlow`）；每张子流程图通过一个子流程节点被包含，不能被多个父节点共享为不同实例。
- `session` 类型节点为叶节点，引用一个真实会话；`subflow` 类型节点有唯一 `childFlowId`，自身并不指向真实 Agent CLI 会话。
- 节点的 `parentFlowId` 指向它所属的流程；创建与移动时必须检查包含关系不构成环。
- 即使改变一个子流程的位置，其所有后代会话的稳定 node ID 和跨组真实边端点都不随之改变。
- 开发文档使用 `01.01` 等编号；运行时节点使用稳定的业务 ID。两套 ID 不混用。
