## 4. 准备如何开发或改造

树状目录以节点 ID 为主键，允许定位、聚焦、打开祖先流程。。实现时：与画布共享节点 ID 和层级数据；大纲不维护另一套会话树；跳转时保留面包屑。 与 以纯 TypeScript 类型及运行时校验基础类型定义唯一数据契约；禁止在 Flow 对象中保存所谓父流程聚合边。。关键异常必须有明确处理结果，不能仅改变画布表现而绕过真实数据校验。

### 大纲与画布联动

同一个节点可以从大纲、全局视图、分层视图进入；三处必须用同一个 `nodeId` 定位。大纲展开/收起不改变层级关系或真实边；跳转到会话时先展开其祖先路径，分层视图定位到该会话所在流程，必要时再打开会话详情。用户从详情返回时应恢复原视图与浏览位置。
