## 4. 准备如何开发或改造

先恢复图，再核对进程或适配器恢复能力；失败显示已断开而非假运行。。实现时：持久会话状态不同于 OS 进程存活；不能仅凭数据库 running 标志认定进程仍运行。 与 会话 ID 与图节点 ID 明确分离；关闭前台面板不停止进程；崩溃后对未能恢复会话显示状态。。关键异常必须有明确处理结果，不能仅改变画布表现而绕过真实数据校验。
