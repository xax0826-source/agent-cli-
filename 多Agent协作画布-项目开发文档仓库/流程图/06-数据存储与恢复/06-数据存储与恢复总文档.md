## 3. 节点职责

- **06.01 数据模型与写入**：持久化流程层级、会话节点、真实边和模型配置。。开发入口见任务 T-01。

## 4. 与其他系统的交接

输入：图编辑、配置、消息事件；输出：查询、恢复状态和历史事件。 相关关系见[00 整体总览](../00-整体总览.md)；具体开发入口见下方任务行。

## 5. 当前开发或改造方案

建议以本地数据库保存稳定的 Flow/Node/RealEdge 与会话配置；只保存真实边，绝不保存投影聚合边。会话恢复必须核对 CLI 进程或适配器实际状态，不能把数据库中的 running 当作真实运行中。

本系统属于从零开发的**目标设计**，暂无已完成产品功能。技术选型均为建议或待验证方案，真实实现与验收进度应从文件开发文档更新。
